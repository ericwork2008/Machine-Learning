# Neural Networks

不要把神经网络看成一堆公式，而是把它看成一个不断循环的学习过程：

1. **Forward Pass**：模型根据当前参数做出预测（"我现在认为答案是什么？"）。
2. **Loss Function**：衡量预测与真实值之间的差距（"我错了多少？"）。
3. **Gradient（梯度）**：告诉模型每个参数应该往哪个方向调整，以及调整多少（"怎样改会让错误变小？"）。
4. **Initialization（初始化）**：给模型一个合适的起点，避免所有神经元学成一样，也避免梯度消失或爆炸。
